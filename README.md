## Projects

### [route_env](https://github.com/rohg0614/route_env) — Ride Dispatch Optimization Environment

A graph-based custom OpenEnv environment for reinforcement learning research.

- **Agent design** — controls a single driver across a zone graph; actions include wait, accept ride, or reposition
- **Stochastic demand** — ride demand shifts dynamically over time, requiring adaptive decision-making
- **RL-ready** — structured as a Gymnasium-compatible environment for plug-in with PPO, DQN, and other algorithms
- **Stack** — Python · NetworkX · OpenEnv · Dockerfile

> Explores how RL agents learn optimal dispatch strategies under uncertainty.

---

### [GlucoPulse](https://github.com/rohg0614/diabetes-tool) — Diabetes Health Analytics Platform

End-to-end ML system for clinical risk prediction and patient management.

- **Deep learning** — Keras + TensorFlow neural network predicting diabetes progression from biomarker data
- **Explainability** — XGBoost with SHAP values for interpretable, clinician-facing risk scores
- **Backend** — FastAPI + PostgreSQL on Neon; full REST API
- **Frontend** — Vite + React + TypeScript production UI; Streamlit prototype
- **Data pipeline** — Pandas + NumPy preprocessing: normalisation, feature scaling, dropout regularisation, early stopping
